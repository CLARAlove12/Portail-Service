# Portail des services

## Présentation du projet

Le Portail des services est une plateforme web destinée à centraliser les services proposés aux étudiants du campus. Il permet de consulter les services disponibles, de découvrir leurs caractéristiques et de suivre les demandes effectuées.

## Équipe de développement

- **ADETOU Clarisse** — Développeuse

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Vite

## Installation et lancement

Cloner le dépôt :

```bash
git clone URL_DU_DEPOT
```

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```

## Structure du projet

Le projet est organisé autour de pages HTML, de composants réutilisables et de ressources statiques.
